# Оно тебе надо

Проектная работа Яндекс Практикума: вёрстка страницы аукциона вещей, в которые никто не верил.

Репозиторий проекта: https://github.com/mhmsangare-ship-it/ono-tebe-nado-ad

## Структура проекта

- `index.html` — разметка страницы
- `styles/global.css` — глобальные стили
- `styles/style.css` — стили проекта
- `fonts/` — шрифты Raleway и файл подключения `fonts.css`
- `images/` — изображения (фон обложки, фоны карточек, логотипы, иконки соцсетей)

## Запуск

Откройте файл `index.html` в браузере — дополнительные инструменты не нужны.
